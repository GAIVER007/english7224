# SpeakUp / English7224

Личное приложение для практики английского. Основной маршрут A0–C1:
**72 темы, 432 вопроса, чтение, аудирование, письмо и устная практика**.
На каждом этапе — мини-экзамены и итоговая контрольная. Речь и письмо
проверяются самостоятельно по образцам; прохождение не является сертификацией CEFR.

Дополнительно сохранены **30 разговорных миссий в 6 модулях, 156 слов с примерами**
уровней A2 → B1 и весь прежний прогресс.

## Возможности

- Основная программа A0–C1 с выбором этапа, сохранёнными черновиками и историей.
- Ориентировочный тест для старта и отдельные дополнительные разговорные миссии A2 → B1.
- Шесть последовательных этапов: повторение, слова, фразы, диалог,
  речевая практика и обязательный мини-экзамен (минимум 6 из 7).
- После каждых пяти миссий — экзамен модуля: минимум 12 из 15.
  Он проверяет материал всех пяти миссий и открывает следующий модуль.
- Экзамены проверяют вспоминание слов, понимание фраз и грамматику; есть
  объяснения ошибок и пересдача. При недоступной озвучке доступен текст.
- Пройденные миссии можно открыть снова: материал, речь и проверка без повторного XP.
- Интервальное повторение с возвратом ошибочных карточек сразу.
- XP за завершение этапов без повторных наград; серия дней и статистика.
- Мобильный интерфейс с нижней навигацией, крупными кнопками и safe-area.
- Неделя практики без квоты действий: календарь занятий и четыре направления практики.
- «Вызов памяти»: написать английское слово по русской подсказке, затем повторить ошибки.
- Пять достижимых игровых рангов и награды за практику (это не оценка CEFR).
- Личный рейтинг с шестью лигами, лучшей серией и числом дней занятий.
  Баллы: 20 за тему новой программы или уникальную миссию, 50 за контрольную или сданный модуль, 5 за речевой этап старых миссий,
  10 за день практики (первые 100 дней). Пропуски и пересдачи не уменьшают рейтинг.
  Всего 10 достижений; полученные награды сохраняются вместе с прогрессом.
- Проверка изученных слов, фраз и аудирования с сохранением последнего результата.
- История завершённых экзаменов миссий, модулей и проверок навыков в «Мой рост».
  Новые попытки сохраняются отдельно, включая неудачные пересдачи. Интерфейс показывает
  по 10 записей, резервная копия включает весь журнал. Старые попытки, для которых
  раньше сохранялся только последний результат, восстановить невозможно.
- Прогресс в localStorage, синхронизация вкладок и безопасный сброс только данных SpeakUp.
  Данные привязаны к адресу и браузеру: локальная версия и публичный сайт имеют отдельные
  хранилища. После входа прогресс синхронизируется между устройствами через Supabase.
  Для переноса без аккаунта используется JSON-копия. Очистка браузера удаляет локальные данные.
- Резервная копия JSON: скачать и восстановить через «Мой рост → Мои настройки».
  Перед заменой показан предпросмотр; повреждённые файлы отклоняются.
- Манифест, иконки и офлайн-запуск основных разделов после первого открытия production-версии.
- Браузерная озвучка; распознавание речи с обработкой ошибок и самостоятельной альтернативой.

Распознавание сравнивает текст, а не качество произношения. Браузер может
использовать внешний сервис для распознавания аудио. Запись запускается только
по нажатию пользователя. В неподдерживаемом браузере доступна самостоятельная практика.

## Персональный план

На главной показано одно рекомендуемое действие. Незаконченный урок и обязательный
экзамен имеют приоритет; повторение учитывает срок карточек. «Другой вариант»
оставляет доступ к следующему уроку, ошибкам и практике. Грамматика рекомендуется
при результате ниже 80% последних 20 ответов, после минимум 10 попыток.
Это локальные правила персонализации, а не генеративная модель.

## Быстрый перевод

Открой «Перевод» в нижнем меню. RU ↔ EN определяется автоматически, язык можно
выбрать вручную. Есть обмен языков, озвучка исходника/перевода и копирование.
После паузы 650 мс текст переводится локальными моделями OPUS-MT в Web Worker.
Суточной квоты нет. До 5 000 символов за один ввод — защита памяти телефона;
длинный текст автоматически разбивается на небольшие части.
Последние 50 переводов кешируются только в памяти экрана, история не сохраняется.

Перед первым переводом нажми «Скачать языковые пакеты»: две квантованные модели
RU ↔ EN загружаются с Hugging Face (несколько сотен МБ, лучше Wi-Fi) в Cache API
этого браузера. Версии моделей закреплены; после загрузки перевод не обращается
к внешнему API и не отправляет текст. В памяти находится только одна модель; используется один вариант декодирования, чтобы снизить задержку на телефоне.
Лицензии и источники: [public/model-licenses.txt](public/model-licenses.txt).

Офлайн-запуск приложения включён в production-сборке: дождись сообщения
«Можно заниматься без интернета». Service worker сохраняет разделы и локальный
WASM runtime отдельно от моделей. Обновление приложения не удаляет языковые пакеты.
Новая версия устанавливается по кнопке, не прерывая текущую тренировку.
Браузер может удалить кеш при нехватке места; тогда пакеты нужно скачать повторно.
Скорость и качество зависят от устройства и модели. Озвучка без интернета требует
установленного системного голоса; распознавание речи может требовать сеть.

## Локальный запуск

Нужны Node.js 22.12+ и Bun 1.3+. Проверено на Node 24.19 и Bun 1.3.14.

```sh
bun install --frozen-lockfile
bun run dev --host 127.0.0.1 --port 5173
```

Если загрузка зависает на IPv6, для этой команды можно выбрать IPv4:

```sh
bun --dns-result-order=ipv4first install --frozen-lockfile --network-concurrency=8
```

Для проверки офлайн-режима (HTTPS либо localhost; dev-сервер его не включает):

```sh
bun run build:local
bun run preview:local
# http://127.0.0.1:4174/translate
```

## Свободный тренажёр грамматики

На главной есть отдельный тренажёр, доступный после выбора уровня, без
необходимости завершать миссии. 216 собственных комбинаций: четыре местоимения,
шесть глаголов, три времени Simple и три типа предложения. Можно выбрать время
и тип, собирать фразу из слов с лишними вариантами или вводить ответ самому.
Сокращения do not/don't, does not/doesn't, did not/didn't, will not/won't
и he/she/we/they'll принимаются. Это закрытые упражнения с указанным глаголом,
а не автоматическая проверка любых переводов.

Серии по 10 заданий, разбор конструкции после ответа, повтор сложных заданий
и новые серии без лимита. Сохраняются последние 100 ответов; подсказка и пропуск
не засчитываются как самостоятельный ответ. История входит в резервную копию.
Завершение серии по кнопке добавляет одно действие к дневной активности, без XP.
Старые сохранения получают пустую историю без сброса прогресса.

Идеи механики изучены по открытым описаниям
[официального приложения](https://apps.apple.com/ru/app/id631311961) и
[тренажёра «Полиглот 16»](https://play.google.com/store/apps/details?id=com.kostosha.poliglot16.lite).
Использованы общие принципы: конструкции, сборка фразы, справка, свободная практика.
Задания и код написаны для SpeakUp; материалы курса и интерфейс не копировались.
Текущий тренажёр охватывает только Simple обычных глаголов, не все 16 уроков.

## Голосовой репетитор Mira

Откройте «Разговор с Mira» с главной и выберите тему и уровень. Если потребуется
вход, после него вы вернётесь к выбранному занятию. Нажмите «Начать звонок».
Для звонка нужны интернет и разрешение на микрофон. После завершения на странице
появятся конспект и домашнее задание. Выполнение задания отмечается галочкой.
История входит в прогресс аккаунта и резервные копии. Аудиозапись звонка
приложение не сохраняет.

В разделе «Задания от репетитора» нажмите «Добавить задание». Выберите текстовый
PDF, DOCX или TXT до 10 МБ либо вставьте текст вручную. Проверьте извлечённый
текст, оставьте упражнения на одно занятие (до 8000 знаков) и сохраните.
Документ читается в браузере. В прогресс и резервную копию входят название,
текст и отметка выполнения. Для PDF-сканов потребуется предварительное распознавание.

Выберите сохранённое задание и нажмите «Разобрать с Mira». Mira задаёт вопросы
по упражнению по одному. При следующем разборе того же задания ей доступен
конспект предыдущего разговора по нему. В карточке «С чего продолжить» видно
следующее упражнение, если его удалось определить по разговору. После обрыва
связи доступна предыдущая сохранённая подсказка. К последнему незавершённому
заданию ведёт кнопка «Вернуться к заданию». Отметку «Задание выполнено» ставит ученик.

Для разработки и публикации задайте на сервере `LOVABLE_API_KEY`, `SUPABASE_URL`
и `SUPABASE_PUBLISHABLE_KEY`. Браузер использует существующие публичные настройки
Supabase. Сервер должен принимать WebSocket на `/api/tutor/live`, браузер — работать
на HTTPS или localhost. Голос использует `openai/gpt-live-1`, подсказки и конспект —
`openai/gpt-5.4-mini` через Lovable AI Gateway.

## Речевая практика

На главной доступна «Лаборатория речи» по пройденным миссиям:

- Аудиодиктант из трёх фраз, обычная и замедленная озвучка, ввод без подсказок,
  разбор и список фраз для повторения. Открытый текст не засчитывается как аудирование.
- Пересказ со скрытием диалога и самостоятельной проверкой содержания.
- Собственная реплика в диалоге: ввод до показа примера, сравнение без
  автоматической оценки свободного ответа.

Завершённая тренировка добавляет одно действие в дневную активность, без XP
за повторное прохождение миссии. Ответы в этих режимах не отправляются на сервер
и не сохраняются после выхода. Озвучка зависит от системного английского голоса.

## После последней миссии

После экзамена шестого модуля остаются интервальное повторение, вызов памяти,
повторная речевая практика любой миссии и недельная проверка. Можно заниматься
ежедневно: сначала слова к повторению, затем рассказ вслух по пройденной теме,
раз в неделю — проверка. Темы B2 и C1 доступны в программе A0–C1.
Старые XP и пройденные миссии сохраняются; пропущенные экзамены модулей нужно
сдать по порядку перед продолжением.

## Ограничения и план

Без входа прогресс хранится в браузере. Для вошедших пользователей настроена синхронизация через Supabase. Приоритеты для личного использования: больше разговорных сценариев,
проверка установки и производительности моделей на реальном телефоне. Аккаунты и сервер не обязательны. Тест уровня не является
сертификацией CEFR. Подробный аудит и оставшаяся работа: [docs/READINESS.md](docs/READINESS.md).

Проект связан с [Lovable](https://lovable.dev/projects/lovp_0thtft4d3p970btvm97s3db5jp).
Историю опубликованных коммитов нельзя переписывать; изменения main синхронизируются
с редактором Lovable. Чтобы обновить `english7224.lovable.app`, откройте этот
проект и нажмите **Publish → Publish changes**.


## Учебные принципы и геймификация

- Квота 3/5/10 действий убрана из интерфейса. Старое поле сохраняется только для совместимости резервных копий.
- За последние семь местных календарных дней показаны реальные дни активности и виды занятий:
  слова/фразы, понимание, собственная речь, беглость. Повтор одной категории не заполняет другие.
- Направления записываются с этого обновления, прошлые занятия не реконструируются. Это факт
  практики, не оценка уровня или учёт равного времени по четырём направлениям.
- «Говорить свободнее» в лаборатории речи: три рассказа о знакомой ситуации, на последнем
  проходе заметки скрыты. Самопроверка обязательна на каждом проходе; автоматического измерения
  произношения, скорости и дополнительных XP нет.
- Следующее достижение показано с конкретным условием. Пропуски не отнимают накопленные награды.
- Интервальные карточки, активное вспоминание и применение материала в пересказе сохраняются.

Основания: [AERO — spacing and retrieval](https://www.edresearch.edu.au/guides-resources/practice-guides/spacing-and-retrieval-practice-guide-full-publication),
[Paul Nation — four strands](https://openaccess.wgtn.ac.nz/articles/journal_contribution/The_four_strands_of_a_language_course/12560387).
Это практические адаптации принципов, не обещание гарантированного результата или полного курса языка.

### Темы и отложенное закрепление

Свободный тренажёр показывает девять тем Simple и короткое правило перед
раундом. В каждой теме 24 оригинальные фразы. Ответы сохраняются отдельно
по фразам в `grammarCards`; наступившие повторения доступны одной кнопкой.
Немедленное повторение не повышает ступень закрепления. Новые данные входят
в JSON-резервную копию; старые сохранения совместимы. После ответа можно
послушать фразу системным синтезатором речи.

[Сравнение с публичными механиками English Galaxy](replica/recon.md)
показывает источники, принятые решения и ограничения. Полный курс A0–C1 и
чужие учебные материалы этим изменением не добавляются.

## Программа A0–C1

Новый раздел `/course`: 72 темы, по 12 на этап. Каждая включает правило,
словарь, чтение, аудирование, письмо, устную практику и мини-экзамен.
После тем доступна контрольная этапа. Черновики, ответы, результаты и история
сохраняются в `pathway`, входят в backup и учитываются в личном рейтинге.
Старые разговорные миссии остаются доступны с прежним прогрессом.

[Покрытие, правила прохождения и ограничения](docs/program-a0-c1.md).
Самопроверка речи и письма не является автоматической оценкой CEFR.
