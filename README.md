# SpeakUp / English7224

Личный мобильный тренажёр разговорного английского. Текущая программа:
**10 уроков A2, 56 слов** — ресторан, аэропорт, small talk, отель, покупки,
транспорт, повседневные дела, встречи, просьбы о помощи и работа.

## Возможности

- Ориентировочный тест уровня и ручной выбор A1–C1. Содержание текущего курса — A2.
- Шесть последовательных этапов: повторение, слова, фразы, диалог,
  речевая практика и мини-тест (порог завершения 70%).
- Интервальное повторение с возвратом ошибочных карточек сразу.
- XP за завершение этапов без повторных наград; серия дней и статистика.
- Мобильный интерфейс с нижней навигацией, крупными кнопками и safe-area.
- Цель на день: 3, 5 или 10 действий; настоящая история активности за неделю.
- «Вызов памяти»: написать английское слово по русской подсказке, затем повторить ошибки.
- Пять достижимых игровых рангов и награды за практику (это не оценка CEFR).
- Проверка изученных слов, фраз и аудирования с сохранением последнего результата.
- Прогресс в localStorage, синхронизация вкладок и безопасный сброс только данных SpeakUp.
- Резервная копия JSON: скачать и восстановить через «Мой рост → Мои настройки».
  Перед заменой показан предпросмотр; повреждённые файлы отклоняются.
- Манифест и иконки для главного экрана телефона. Для открытия пока нужен интернет.
- Браузерная озвучка; распознавание речи с обработкой ошибок и самостоятельной альтернативой.

Распознавание сравнивает текст, а не качество произношения. Браузер может
использовать внешний сервис для распознавания аудио. Запись запускается только
по нажатию пользователя. В неподдерживаемом браузере доступна самостоятельная практика.

## Быстрый перевод

Открой «Перевод» в нижнем меню. RU ↔ EN определяется автоматически, язык можно
выбрать вручную. Есть обмен языков, озвучка исходника/перевода и копирование.
После паузы 650 мс отправляется короткая фраза (до 240 символов / 500 байт).
Устаревшие запросы отменяются; последние 50 успешных переводов кешируются только
в памяти открытого экрана. История не попадает в localStorage или резервную копию.

Перевод выполняет [MyMemory](https://mymemory.translated.net/doc/spec.php)
через серверный POST `/api/translate`, без ключей и регистрации.
[Анонимная квота](https://mymemory.translated.net/doc/usagelimits.php) — 5 000
символов в день; она общая для исходящего IP сервера. Это вариант для личного
приложения, не готовая схема для публичного многопользовательского сервиса:
перед таким запуском нужны авторизация, распределённые лимиты и подходящая квота.
Проверка Origin не является защитой от прямых скриптов, умеющих подставить заголовок.
Текст отправляется MyMemory; наш код не сохраняет/не журналирует его, не передаёт
пользовательский IP/email и не вызывает API добавления переводов. Качество и
доступность зависят от провайдера; офлайн-перевода нет. Таймаут провайдера — 8 секунд.

## Локальный запуск

Нужны Node.js 22.12+ и Bun 1.3+. Проверено на Node 24.19 и Bun 1.3.14.

```sh
bun install --frozen-lockfile
bun run dev --host 127.0.0.1 --port 5173
```

Если загрузка зависает на IPv6, для этой команды можно выбрать IPv4:

```sh
bun --dns-result-order=ipv4first install --frozen-lockfile --network-concurrency=8
```

## Проверки

```sh
bun run typecheck
bun run lint
bun run test
bun run build
# все проверки последовательно:
bun run check
```

Сборка использует конфигурацию Lovable / TanStack Start / Nitro для Cloudflare.
Локальный запуск не публикует приложение. Существующий публичный сайт:
https://english7224.lovable.app — локальные изменения туда автоматически не попадают.

## Ограничения и план

Аккаунтов, сервера и синхронизации между устройствами пока нет. Очистка данных
браузера удаляет локальный прогресс. Приоритеты для личного использования: больше разговорных сценариев,
офлайн-режим и проверка установки на реальном телефоне. Аккаунты и сервер не обязательны. Тест уровня не является
сертификацией CEFR. Подробный аудит и оставшаяся работа: [docs/READINESS.md](docs/READINESS.md).

Проект связан с [Lovable](https://lovable.dev/projects/b338cfa4-0c74-4347-aae7-c2e52c3a88a3).
Историю опубликованных коммитов нельзя переписывать; изменения main синхронизируются
с редактором Lovable.
